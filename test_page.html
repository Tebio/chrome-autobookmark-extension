AutoBookmark 智能书签栏

将鼠标移到屏幕最顶部边缘，即可唤出自动隐藏的悬浮书签栏！

✅ Google Chrome ✅ Microsoft Edge ✅ Brave Browser ✅ Opera & Opera GX ✅ Vivaldi & Arc

🚀 如何安装与测试

本扩展通过 GitHub Release 分发。在 Chromium 内核浏览器中加载已解压的扩展即可使用。

1
打开浏览器扩展管理页面：
chrome://extensions 或 edge://extensions 或 brave://extensions
2
在右上角开启 开发者模式。
3
点击左上角的 加载已解压的扩展程序。
4
选择项目根目录（包含 manifest.json 的文件夹）。
5
完成！ 打开任意网页（或刷新本页），将鼠标移到屏幕顶部 8px 范围内即可看到悬浮书签栏。

⚡ 主要功能

✨ 智能悬停触发
鼠标进入屏幕边缘时平滑滑出，离开后自动收回。
📁 多级文件夹
完整支持多层嵌套文件夹与子菜单导航。
📌 一键固定
按 Alt + B 或点击固定按钮，让书签栏常驻显示。
🔍 快速搜索
在悬浮书签栏内即时搜索所有书签。
🎨 5 款主题
Edge 原生（默认）、深色玻璃、浅色、AMOLED 黑、经典 Chrome。
🛡️ Shadow DOM 隔离
完全避免与访问网页的 CSS 发生冲突。
试一试： 将鼠标移到浏览器窗口的最顶部边缘！
